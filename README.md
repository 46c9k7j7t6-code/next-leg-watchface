
# Next Leg

**One glance. Everything you need. Nothing you don't.**

Next Leg is a Pebble Time 2 watchface designed specifically for airline crew. Import your work schedule through the Pebble app and instantly view your next flight, including flight number, route, gate, departure time, and live flight status.

---

## Features

### Version 1.0

- Large local time display
- UTC hour
- Optional Bluetooth indicator
- Optional Battery indicator
- Flight number
- Route
- Gate
- Departure time
- Flight status
- Clean, aviation-inspired design
- Optimized for Pebble Time 2 (Emery)

---

## Planned Features

- FlightAware integration
- AI schedule import
- Airline selection
- Optional airline logos
- Configurable display options
- Light/Dark themes
- Multiple upcoming flights

---

## Design Philosophy

Next Leg is designed around a simple principle:

> **One glance. Everything you need. Nothing you don't.**

Every feature must help an airline crew member find the information they need as quickly as possible.
